Kannada Rajyotsava 2026 website

Deploy to Vercel:
1. Extract this ZIP.
2. Create a GitHub repository and upload index.html + poster.png (or drag the folder into Vercel deployment).
3. In Vercel: Add New Project -> import repository -> Deploy.
4. Copy deployed URL and create a QR code pointing to that URL.

No build command needed; this is a static website.
